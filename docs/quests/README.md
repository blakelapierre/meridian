# Quests

The concept refuses a theme park. A quest is never a UI. There is no log, no tracker, no next-step line, and no turn-in.

A quest exists only as:

- a note the character was skilled enough to write
- lore that is already in the world
- something one person says to another

| Note | What it is |
|---|---|
| [beach.md](beach.md) | What the atoll paper says. The client does not display it as goals |
| [later.md](later.md) | Contracts that are not in the build |

Automated notes are allowed. They record what you did or learned. They never tell you what to do next.
