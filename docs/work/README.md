# Working notes

[game.md](../game.md) is the rulebook. [concept.md](../concept.md) is the logline. A note says what the build does now.

Beach notes and concept notes are both live. The cycle is two steps. First implement whatever **Next** still says is unbuilt. Then develop every note again, and leave that new **Next** unbuilt for the following cycle.

**This pass** and **In the build** say only what the code does. **Next** is not in the build.

The last slice landed the next line of each note again: a shot that is silent past its range, blood loss that drops the body, a vote on the line, three clocks nobody picks, a melee swing, an order the other person can refuse, a certified slump peers apply off the beach, a culture you can leave without the kit you woke with, a lapse the other client is told about, the hammer's quarter turn on 2, a phrase that imports the key without the book, a road that forks twice, a herd, a fin that faces the sun, a beach dig the crust answers, a charter piece, a drag they can refuse, wind on a sail, a paper you can pick up, a township purse, a plant, rain on a pool, a harm message on its own channel, and a door that closes a span. The chart already drew the sight edge. The pose wire and the ray trace were not touched. `test/slice.test.js` covers that slice.

The prose for the world is in [docs/lore](../lore/README.md). The errands are in [docs/quests](../quests/README.md).
