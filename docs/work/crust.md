# Crust

## In the build

The beach is a crust field. A dig writes air, sample `500`, inside the brush. The edit is a signed proposal. A peer seals it. The chain can make it official. A pit is the column floor under your feet, and the map paints it once you have looked at it.

## This pass

Smooth is a third edit mode. It moves a voxel toward zero, at most 500 mm, and refuses a change that would go farther or away from the surface. It does not spend spoil.
