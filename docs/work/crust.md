# Crust

## In the build

The beach is a crust field. A dig writes air, sample `500`, inside the brush. The edit is a signed proposal. A peer seals it. The chain can make it official. A pit is the column floor under your feet, and the map paints it once you have looked at it.

An edit whose mode is slump is refused. Certified sand does not slump through that path. Off the beach, a slump write can be certified and the crust takes the step. On the beach the same slip is not certified, and nothing is written.

## This pass

Peers accept a certified slump from off the beach. A beach slump is still refused. The bit does not send the slump it writes.
