# Identity

From the concept. A key you hold. Not an account we own.

## In the build

Each client mints an Ed25519 key and signs proposals, shots, walls, lore, and pieces. O prints the key on the line. A new tab can paste it as `?key=`. The same pubkey keeps the bind. The peer id can still change. Losing the page without the paste still loses the key.

A harm line keeps one signature byte. It is not delivered to an archive. An archive can keep a signature on the harm note. Shift-O stores the current key in a book under its phrase, and that phrase restores the key from the book. A phrase with no book does not import the key.

## This pass

Alt O prints a phrase that imports the key. The book is not required. A six-word phrase still needs the book.

## Proves

`test/slice.test.js` covers the round trip, and that the short phrase does not import.
