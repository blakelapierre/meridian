# Planet

From [concept.md](../concept.md). Working name **Cairn**. One world, no shards, no reboot.

## In the build

The playable ground is still the Atoll tangent. Gravity is radial, toward a core 320 km down. The drop of that sphere is computed. At a kilometer it is about a meter and a half. The picture does not yet bend the beach.

## This pass

The chart readout names the sense radius beside the fix. `drop` stays on the status line when the shell is more than 2 cm down. The picture is still flat.
