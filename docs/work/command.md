# Command

From the concept. The chair is a place, and it is vulnerable.

## In the build

There is no war table, no overhead, and no company wallet. The AI clients are people, not orders.

Using the table while you are beside it and not in a strike sits you down. Walking stands you up. Sitting gives the order `hold` to each other body you can see. They are not asked, and they cannot refuse.

## This pass

The order is given to the other bodies, not only drawn on the chart.

## Proves

`test/slice.test.js` covers the order word on an id. The chart still draws `hold`.
