# Lore

The prose lives in [docs/lore](../lore/README.md). This note is what the build is allowed to say.

## In the build

There is no narrator and no quest line. The names in the world are Cairn, Atoll, the compound, the dummy, and the footing. The character's own notes are the only new sentences, and only when a skill clears the bar in [the paper note](../quests/beach.md).

A charter names its first person as voucher, on the line. Identifying the table reads its voucher, or `unsigned` when it has none.

## This pass

Sitting at the table writes `self` as its voucher. Identifying the table reads that name.

## Proves

`test/slice.test.js` covers the write.

## Next
