# Water

From the concept. The crust is the only map. Water is part of the crust.

## In the build

The sea is still the edge of the beach. A dug pit whose floor is below −0.2 m holds a pool. The pool sits in that hole. It does not run downhill.

## This pass

A pool may step twice in the same second, half a meter each time, and only downhill. Filling the hole still removes it.
